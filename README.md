## Роуты

### Получение информации о файле

`GET /files/info?path={path}`

Параметры запроса:

- `path` — абсолютный путь к файлу.

Успешный ответ: `200 OK`.

Поле `Data` содержит информацию о файле:

```json
{
  "Name": "example.txt",
  "FullName": "/home/user/example.txt",
  "Type": "file",
  "Size": 1024,
  "Inode": 12345,
  "Links": 1,
  "DeviceID": 2049,
  "RDevice": 0,
  "BlockSize": 4096,
  "Blocks": 8,
  "Owner": "user",
  "OwnerID": 1000,
  "Group": "users",
  "GroupID": 1000,
  "LinkTarget": "",
  "SpecialPermissions": [],
  "UserPermissions": ["read", "write"],
  "GroupPermissions": ["read"],
  "OthersPermissions": ["read"],
  "BirthDateTime": "2026-09-17T12:00:00Z",
  "ModificationDateTime": "2026-09-17T12:00:00Z",
  "ChangeDateTime": "2026-09-17T12:00:00Z",
  "AccessDateTime": "2026-09-17T12:00:00Z"
}
```

### Создание файла

`POST /files?path={path}`

Параметры запроса:

- `path` — абсолютный путь к создаваемому файлу.

Успешный ответ: `201 Created`.

Тело ответа не содержит данных.

### Удаление файла

`DELETE /files?path={path}`

Параметры запроса:

- `path` — абсолютный путь к удаляемому файлу.

Успешный ответ: `200 OK`.

Тело ответа не содержит данных.

### Переименование файла

`PATCH /files/name?path={path}`

Параметры запроса:

- `path` — абсолютный путь к файлу.

Тело запроса:

```json
{
  "NewFileName": "new-name.txt"
}
```

Поля тела запроса:

- `NewFileName` — новое имя файла без пути.

Успешный ответ: `200 OK`.

Тело ответа не содержит данных.

### Перемещение файла

`PATCH /files/location?path={path}`

Параметры запроса:

- `path` — абсолютный путь к перемещаемому файлу.

Тело запроса:

```json
{
  "DestinationPath": "/home/user/documents/example.txt"
}
```

Поля тела запроса:

- `DestinationPath` — абсолютный путь назначения.

Успешный ответ: `200 OK`.

Тело ответа не содержит данных.

### Копирование файла

`POST /files/copy?path={path}`

Параметры запроса:

- `path` — абсолютный путь к копируемому файлу.

Тело запроса:

```json
{
  "DestinationPath": "/home/user/copy.txt"
}
```

Поля тела запроса:

- `DestinationPath` — абсолютный путь создаваемой копии.

Успешный ответ: `201 Created`.

Тело ответа не содержит данных.

### Перезапись содержимого файла

`POST /files/write?path={path}`

Параметры запроса:

- `path` — абсолютный путь к файлу.

Тело запроса:

```json
{
  "Content": "Новое содержимое файла"
}
```

Поля тела запроса:

- `Content` — содержимое, полностью заменяющее текущие данные файла.

Успешный ответ: `200 OK`.

Тело ответа не содержит данных.

### Добавление содержимого в файл

`POST /files/append?path={path}`

Параметры запроса:

- `path` — абсолютный путь к файлу.

Тело запроса:

```json
{
  "Content": "Добавляемое содержимое"
}
```

Поля тела запроса:

- `Content` — содержимое, добавляемое в конец файла.

Успешный ответ: `200 OK`.

Тело ответа не содержит данных.

### Чтение содержимого файла

`GET /files/content?path={path}`

Параметры запроса:

- `path` — абсолютный путь к файлу.

Успешный ответ: `200 OK`.

Поле `Data` содержит строковое содержимое файла:

```json
{
  "IsSuccess": true,
  "Data": "Содержимое файла",
  "Error": null
}
```

## Ошибки

Основные коды ошибок:

- `400 Bad Request` — передан относительный путь, некорректный JSON, путь указывает на каталог или передан недопустимый аргумент;
- `403 Forbidden` — недостаточно прав или файловая система доступна только для чтения;
- `404 Not Found` — файл или каталог не найден;
- `409 Conflict` — файл уже существует, ресурс занят, каталог не пуст или операция выполняется между файловыми системами;
- `413 Request Entity Too Large` — файл превышает допустимый размер;
- `507 Insufficient Storage` — недостаточно свободного места;
- `500 Internal Server Error` — неизвестная ошибка сервера или файловой системы.
